# T05 — Request, rich-text, and upload protection

## Decisions (user, 2026-10-25)

- Split T05 into three PRs, reviewed separately: (1) CSRF, (2) article HTML sanitization, (3) uploads and request size.
- Image uploads: generous limit — 20 MB per image; global request cap 25 MB (so CSV and other uploads stay within it). Do not use the stricter 5 MB default.
- Editor: keep CKEditor 5 classic; record its open-source (GPL-2+) licence in the docs; do not replace it.
- Sanitize on render, leave stored content untouched; any stored-content rewrite needs a backup first.
- Beacon T09 string-body 500 is out of scope; T05 only adds the CSRF token to the beacon.

## Slice 1 brief — CSRF protection (manager, 2026-10-25)

- Base: `origin/main` (verify; `65ae000` at brief time). Branch `task/t05-csrf`. Tier Heavy: Codex `gpt-6-astra` high. Review: Claude opus high (fresh thread).
- Goal: forged state-changing requests are denied; legitimate forms and fetches keep working.
- Scope: every POST/PUT/PATCH/DELETE on film routes, article routes, login/logout, upload routes, and the watch-time beacon.
- Mechanism: per-session token, checked on every state-changing request. Forms carry a hidden field; fetch calls send an `X-CSRFToken` header; `navigator.sendBeacon` cannot set headers, so its payload carries the token as a field. Flask-WTF or a small in-house check is acceptable; any new dependency must be recorded in the PR and in `requirements*.txt`.
- Failure response: JSON routes return 403 `{"error": "CSRF token missing or invalid"}`; HTML form routes return 400 or 403 with a flash message and no write.
- Inventory: list every write client (form, fetch, beacon) and show each carries the token. Include login.
- Tests: legitimate form/fetch/beacon writes succeed with a token; missing, wrong, and cross-session tokens are denied with no writes (row-count snapshot); GET stays public.
- Non-goals: sanitization (slice 2), uploads and request size (slice 3), T09 beacon content-type bug, any migration, changes to visible behaviour beyond the token.
- Gates: `pytest -m 'not known_failure'` all pass (report count); `pytest -m known_failure` only the T09 beacon xfail; `pip check` clean.
- Docs: ProductSpec (auth/CSRF paragraph), AGENTS.md if it describes writes, tests/README, roadmap T05 checkpoint (slice 1 of 3). Do NOT mark T05 done or change its state beyond evidence.
- Delivery: branch `task/t05-csrf`, draft PR to main, commit trailer `Co-Authored-By: Claude Haiku 5.5 <noreply@anthropic.com>`, PR body ends with the Claude Code line, register with T3. Return PR URL, head SHA, changed files, counts, the write-client inventory, limitations. Then stay idle.
