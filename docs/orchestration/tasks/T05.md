- Base: `origin/main` (verify; `65ae000` at brief time). Branch `task/t05-csrf`. Tier Heavy: Codex `gpt-6-astra` high. Review: Claude opus high (fresh thread).
- Goal: forged state-changing requests are denied; legitimate forms and fetches keep working.
- Scope: every POST/PUT/PATCH/DELETE on film routes, article routes, login/logout, upload routes, and the watch-time beacon.
- Mechanism: per-session token, checked on every state-changing request. Forms carry a hidden field; fetch calls send an `X-CSRFToken` header; `navigator.sendBeacon` cannot set headers, so its payload carries the token as a field. Flask-WTF or a small in-house check is acceptable; any new dependency must be recorded in the PR and in `requirements*.txt`.
- Failure response: JSON routes return 403 `{"error": "CSRF token missing or invalid"}`; HTML form routes return 400 or 403 with a flash message and no write.

- Tests: legitimate form/fetch/beacon writes succeed with a token; missing, wrong, and cross-session tokens are denied with no writes (row-count snapshot); GET stays public.
